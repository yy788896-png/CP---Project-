# Super Market Management System

A simple browser-based academic project based on the supplied project report.

## Features
- Product registration and product list
- Inventory quantity tracking and low-stock alerts
- Billing with automatic total calculation
- Stock deduction after a completed sale
- Sales history and dashboard summary
- Browser local storage for demo data

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Add products, create bills, and review inventory/sales.

No server or database installation is required for this demo. Data remains in the browser where it was entered.

## Deploy with GitHub Pages
1. Create a new repository on GitHub.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. Open the URL shown in the Pages section.

## Important
This is a front-end demonstration for academic use. It does not include a secure login, shared multi-user database, payment gateway, or server-side backup. Do not use it to store real customer or business data.
